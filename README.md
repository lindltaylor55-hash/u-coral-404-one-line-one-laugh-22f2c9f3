Entry for the [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) competition on [make.fun](https://make.fun).

The entry is a single funny line, written to land its laugh on a first read:

> My GPS said 'recalculating' in the exact tone my mother uses when I disappoint her.

`main.ts` (Node 22, stdlib only) writes the line from `entry.txt` to `/output/entry.txt`.
